# أفكار الفيزات القادمة

> قائمة أفكار متفق عليها ولم تُبنَ بعد. كل فكرة تُكتب في `docs/system.md` (وفي الدستور إن لزم) عند بدء فيزتها، لا قبل ذلك.

## حذف مشترك (بعد الفيزة 010)

الهدف: **تصحيح الغلط** (طلب مكرر أو تجريبي)، لا طلبات الخصوصية.

قرارات المالك (23 تشرين الثاني 2026):
- **الشكل: مسح البيانات الشخصية**، لا حذف السطر. تُمسح الأسماء، الرقم الوطني، الرقم العائلي، الهاتف، العنوان، أقرب نقطة، الموقع، بيانات البطاقة والقراءات، التثبيتات، وملفات صور البطاقة من القرص. يبقى سطر فارغ فيه: رقم الطلب، المسوّق، الحالة، التواريخ، البرج، الفئة، السعران. بعدها الهاتف والأرقام ترجع حرّة.
- **الطلبات المسموح حذفها: بالانتظار والمرفوضة فقط.** المقبول والمربوط لا يُحذف (حتى لا تتأثر العمولة والعدّادات).
- صلاحية جديدة «حذف» (`delete`) يعطيها الأدمن الرئيسي، والأدمن الرئيسي عنده ياها دائماً.
- الحذف من ملف الطلب، ويحتاج تأكيد بكتابة رقم الطلب.
- **سبب الحذف** يُختار من قائمة ثابتة بلا بيانات شخصية (مثلاً: طلب مكرر، طلب تجريبي، أُدخل بالغلط).
- سجل العمليات: سطر «حذف مشترك» فيه رقم الطلب، منو حذف، متى، والسبب. بلا أي بيانات شخصية.

ما يحتاج انتباه عند بنائها:
- **تعديل الدستور، المبدأ الثالث**: يسمح بمسح البيانات الشخصية لطلب بالانتظار أو مرفوض، مع بقاء سطر الطلب. تعديل MINOR، وبموافقة المالك.
- الطلبات الأخرى المرتبطة بالطلب المحذوف (عودة، اشتراك إضافي، تعارض) تعرض «سجل محذوف» بدل بياناته.
- النسخ الاحتياطية تحتفظ بالبيانات حتى تنتهي مدتها (30 يوماً للنسخ الليلية، وبلا حد للنسخ الأسبوعية على الهارد الخارجي)، والمالك يعرف هذا.
- رموز التحقق المرتبطة بالهاتف تُحذف، فيصفر حدّ الـ 5 رموز بالساعة لذلك الهاتف.
- رقم الطلب لا يُعاد استعماله.

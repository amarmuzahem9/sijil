# التجربة اليدوية — الفيزة 010: مراجعة الأدمن للطلبات

التجربة على `https://localhost` بمجموعة التطوير. استعمل بطاقتك أنت فقط من جهازك، ولا ترفعها لأي مكان ثاني.

## قبل البدء

1. شغّل `docker compose up -d`، وبعدها `docker compose exec api alembic current`. النتيجة لازم تكون `0013 (head)`.
2. حتى ما تصرف رصيد الرسائل، حط بملف `.env` السطرين `OTP_MODE=fake` و`OTP_FAKE_CODE=246810`، وبعدين شغّل `docker compose up -d api`. رجّعهم لحالتهم بعد التجربة.
3. لازم يكون عندك طلب **مقبول** ببطاقتك، من تجربة 008 أو 009.
4. الحسابات:
   - مسوّق واحد على الأقل؛
   - أدمنين اثنين عندهم صلاحية «مراجعة الطلبات (قبول/رفض)» (`review`)، حتى تجرب القرار من متصفحين؛
   - أدمن عنده «الإعدادات» (`settings`) فقط.
5. كمسوّق، أرسل خمس طلبات تروح للانتظار:
   - **اشتراك ثاني:** رقمك العائلي مع رقم وطني ثاني، و«إضافة اشتراك ثاني»؛
   - **تعديل الأرقام:** غيّر رقماً واحداً من اللي قرأتها البطاقة؛
   - **تعارض بالأرقام:** رقمك الوطني مع رقم عائلي ثاني؛
   - **عودة للخدمة بالرقم الوطني والعائلي**، و**عودة للخدمة بالهاتف**، مثل تجربة 009.

## 1. قائمة «طلبات بالانتظار»

| # | الخطوة | النتيجة المتوقعة |
|---|---|---|
| 1 | ادخل بأدمن المراجعة، وافتح «طلبات بالانتظار» | الطلبات الخمسة، الأقدم فوق. بكل سطر: رقم الطلب، الأسباب، «النوع: …»، المسوّق، اسم المشترك، البرج، ووقت الإرسال بتوقيت بغداد. وفوق «العدد: 5» |
| 2 | اختر «تعارض بالأرقام» من التصفية | يبقى طلب واحد |
| 3 | بعد ما تقرر بكل الطلبات | «لا توجد طلبات بالانتظار» |

## 3. القبول

| # | الخطوة | النتيجة المتوقعة |
|---|---|---|
| 11 | «قبول» على الاشتراك الثاني | تأكيد برقم الطلب وبلا سؤال العمولة. «تأكيد القبول»، فتطلع «مقبول» بالأزرق، و«تم القبول»، و«بواسطة» (اسمك)، و«الوقت» |
| 12 | كمسوّق، افتح نفس الطلب | «تمت الموافقة» مع اليوزر و«نسخ اليوزر». ما يطلع شي عن المشترك القديم ولا اسم الأدمن. ويطلع تحت «مقبولة» |

| 27 | «قبول» على طلب عليه تحذير | تأكيد أحمر «القبول رغم التحذير؟» بيه التحذيرات، وزر أحمر «القبول رغم التحذير». بعد التأكيد يصير مقبول |

## بعد التجربة

- رجّع `OTP_MODE` بملف `.env` لحالته.
- الطلبات المرسلة والقرارات ما تنحذف من التطبيق. أمر مسح بيانات التجربة صار يحتاج يمسح التثبيتات وسجل فتح صور الطلبات قبل الطلبات، فاستعمل هذا بدل أمر 008:

```bash
docker compose exec db psql -U sijil -c "delete from request_number_pins; delete from image_access_log where request_id is not null; delete from request_reasons; delete from request_images; delete from requests; delete from audit_log where action like 'request.%';"
```

# التجربة اليدوية — الفيزة 009: مسارات المشترك الموجود

التجربة على `https://localhost` بمجموعة التطوير. استعمل بطاقتك أنت فقط من جهازك، ولا ترفعها لأي مكان ثاني.

## قبل البدء

1. شغّل `docker compose up -d`، وبعدها `docker compose exec api alembic current`. النتيجة لازم تكون `0011 (head)`.
2. حتى ما تصرف رصيد الرسائل، حط بملف `.env` السطرين `OTP_MODE=fake` و`OTP_FAKE_CODE=246810`، وبعدين شغّل `docker compose up -d api`. رجّعهم لحالتهم بعد التجربة.
3. لازم يكون عندك طلب **مقبول** ببطاقتك. تقدر تستعمل طلب من تجربة 008، أو ترسل طلب نظيف قبل ما تبدي. خلّ نسمّي رقم هاتفه «الهاتف القديم».
4. سوّي مسوّقين اثنين على الأقل، وأدمن عنده صلاحية `settings`.

## 1. العودة للخدمة: نفس الرقم الوطني والعائلي

| # | الخطوة | النتيجة المتوقعة |
|---|---|---|
| 1 | ادخل كمسوّق ثاني، «إضافة مشترك جديد»، وارفع وجه بطاقتك وظهرها | تحت الرقم الوطني يطلع بالأحمر «المشترك لديه اشتراك سابق» وزر «طلب العودة للخدمة». ما يطلع أي اسم أو هاتف أو يوزر للمشترك القديم |
| 2 | اضغط «طلب العودة للخدمة» | يصير «تم اختيار طلب العودة للخدمة: يذهب الطلب لموافقة المسؤول» مع «إلغاء»، ويختفي البند من النواقص |
| 3 | اضغط «إلغاء» | يرجع الزر، ويرجع البند للنواقص |

| 5 | اضغط «إرسال» | تطلع شاشة «بانتظار موافقة المسؤول» مع رقم الطلب، وبمكان اسم المستخدم «بانتظار الموافقة» |

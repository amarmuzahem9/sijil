# التجربة اليدوية — الفيزة 018: ملف المشترك والبحث

التجربة على `https://localhost` بمجموعة التطوير على جهازك فقط. أرقام وأسماء وهمية فقط، وبلا صور بطاقات حقيقية.

## قبل البدء

1. شغّل `docker compose up -d`، وبعدها `docker compose exec api alembic current`. النتيجة لازم تبقى `0020 (head)` (الفيزة بلا ترحيل).
2. الحسابات، يسويها الأدمن الرئيسي:
   - «أدمن المراجعة»: «مراجعة الطلبات (قبول/رفض)» فقط.
   - «أدمن الربط»: «تم الربط والتراجع عنه» فقط.
   - «أدمن التقارير»: «التقارير والتصدير والاستيراد» فقط.
   - «أدمن الإعدادات»: «الإعدادات» فقط.
   - مسوّقين: «المسوّق الأول» و«المسوّق الثاني».
3. البيانات: طلبات تجريبية، وملف مشتركين قدامى تجريبي (014) وملف SAS تجريبي (015)، بينهم:
   - طلب وصف SAS بنفس الهاتف.
   - طلب ومشترك قديم بنفس الرقم العائلي.
   - مشترك قديم حالته «ملغي».
   - طلب مرفوض.
   - طلب محذوف (من «فتح طلب برقمه» ← «حذف»).

## 1. البحث

| # | الخطوة | النتيجة المتوقعة |
|---|---|---|
| 1 | ادخل كأدمن المراجعة وافتح «المشتركون» | مربع البحث وجملة «اكتب اسم أو هاتف أو يوزر أو رقم طلب…». ماكو بحث قبل ما تضغط «بحث» |
| 2 | ابحث بهاتف الطلب المشترك ويّا SAS، بـ `0780 123 4567` ثم بـ `+964 780 123 4567` ثم بالأرقام العربية | نفس النتيجتين كل مرة: «طلب سِجلّ» و«مشترك SAS»، الأحدث فوق |
| 3 | ابحث بالهاتف اللي داخل يوزر SAS (إذا يختلف عن عمود الهاتف) | يطلع صف SAS |
| 4 | ابحث بالرقم العائلي بمسافات وأحرف صغيرة | الطلب والمشترك القديم |
| 5 | ابحث بالرقم الوطني للطلب | الطلب |
| 6 | ابحث بجزء من اسم، وبدّل «أ» بـ «ا» أو «ة» بـ «ه» أو «ى» بـ «ي» | نفس النتائج |
| 7 | ابحث بالرقم القديم «T3C-001»، وبرقم طلب بـ «T3C-» وبدونها، وباليوزر بأحرف صغيرة | السجل المطلوب |
| 8 | ابحث باسم الطلب المرفوض، وباسم القديم «الملغي» | يطلعون ويّا حالتهم |
| 9 | ابحث بهاتف الطلب المحذوف، ثم برقمه | الأولى «لا توجد نتائج»، الثانية «سجل محذوف» برقمه فقط |
| 10 | ابحث بـ «اح» و«%» و«abc» | «اكتب اسماً (3 أحرف على الأقل) أو هاتفاً أو رقماً» |
| 11 | ابحث باسم شائع بملف SAS | العدد الكلي و50 بالصفحة، و«التالي» و«السابق» |

## 2. ملف المشترك

| # | الخطوة | النتيجة المتوقعة |
|---|---|---|
| 1 | افتح الطلب من نتيجة البحث | المصدر والرقم والحالة بلونها والاسم، والهاتف واليوزر والبرج والنوع والمسوّق وتاريخ التسجيل |
| 2 | قسم «المستمسكات» | الرقم الوطني والعائلي وحقول البطاقة والصورتين |
| 3 | افتح صورة، وبعدين شغّل `docker compose exec -T db psql -U sijil -d sijil -c "select user_id, request_id, side, created_at from image_access_log order by id desc limit 3;"` | الفتحة مسجّلة باسمك ورقم الطلب |
| 4 | «السجلات المرتبطة» | صف SAS «نفس الهاتف»، والقديم «نفس العائلة»، والطلب المرفوض لنفس الشخص «نفس الشخص»، والقديم «الملغي» إذا بنفس الهاتف. الطلب المحذوف ما يطلع هنا |
| 5 | اضغط على صف SAS المرتبط | ينفتح ملفه: «… حسب آخر استيراد»، الباقة، آخر اتصال، «بلا مستمسكات في سِجلّ»، و«غير موجود في آخر ملف» إذا موسوم. والطلب مرتبط بيه «نفس الهاتف» |
| 6 | افتح ملف المشترك القديم | الرقم القديم، حالته بالملف، «بيانات إضافية» بلا إيميل، و«غير مكتمل» إذا تنقصه صورة |
| 7 | «سجل الطلب» لطلب انقبل وانربط وصار عليه تراجع | أُرسل، قُبل (أو «قُبل تلقائياً»)، تثبيت رقم «الرقم الوطني» بلا الرقم، تم الربط، تراجع عن الربط ويّا السبب، بالترتيب |
| 8 | افتح الطلب المحذوف برقمه | «سجل محذوف»، رقمه، وسطر «حُذف» ويّا السبب، بلا بيانات شخصية |
| 9 | دوّر بأي ملف على حقل كتابة أو زر تعديل أو حفظ أو حذف | ماكو، الملف للقراءة فقط |
| 10 | سجل سجلاته المرتبطة أكثر من 50 (رقم عائلي مشترك لعائلة كبيرة) | 50 ثم «و N سجلات أخرى» |

## 3. الصلاحيات

| # | الخطوة | النتيجة المتوقعة |
|---|---|---|
| 1 | ادخل كأدمن الربط، وافتح نفس ملف الطلب | الاسم والهاتف واليوزر والسجل والمرتبطين بأسبابهم، **بلا قسم «المستمسكات»**: لا أرقام ولا صور. سطر التثبيت بلا «الرقم الوطني» |
| 2 | كأدمن الربط، اضغط F12 ← Network، وافتح الملف، وشوف Response | ماكو `national_id` ولا `family_number` ولا `card_fields` ولا `images` |
| 3 | كأدمن الربط ابحث برقم وطني موجود، ثم برقم مخترع، ثم برقم عائلي | نفس الرسالة كل مرة: «البحث بالرقم الوطني أو العائلي يحتاج صلاحية المراجعة» |
| 4 | كأدمن التقارير | نفس نتائج أدمن الربط |
| 5 | كأدمن الإعدادات | «المشتركون» ما تطلع بالقائمة، وفتح `/admin/subscribers` يرجعك ويطلع «ليست لديك صلاحية» |
| 6 | كالمسوّق الأول افتح `https://localhost/admin/subscribers` | ما تنفتح |
| 7 | كالمسوّق الثاني ابحث بـ «الطلبات» بهاتف صف SAS أو بهاتف طلب للمسوّق الأول | «لا توجد نتائج» |

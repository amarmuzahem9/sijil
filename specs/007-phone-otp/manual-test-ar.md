# التجربة اليدوية — الفيزة 007: التحقق من هاتف المشترك برمز واتساب

كل تجربة ترسل رسالة حقيقية وحدة بكلفة 25 دينار من رصيد OTPIQ. مفتاح التطوير `sk_dev_` يوجّه كل
الرسائل لتلفونك المسجّل باللوحة، مهما كان الرقم المكتوب بالاستمارة.

## قبل البدء

1. تأكد إن `.env` بيه `OTP_MODE=otpiq` (أو السطر غير موجود)، و`OTPIQ_API_KEY=sk_dev_...`، و`OTP_FAKE_CODE` فارغ.
2. شغّل التطبيق: `docker compose up -d`. إذا غيّرت `.env` شغّل `docker compose up -d api` حتى تقرأ الحاوية المتغيرات الجديدة.
3. تأكد من المايغريشن: `docker compose exec api alembic current`، والنتيجة لازم تكون `0009 (head)`.
4. لازم يكون عندك من الإعدادات: منطقة، وبرج تابع لها، وفئتين على الأقل.

## فحص عدم تسرّب الرمز

نفّذ هالفحوص بعد الخطوة 8، وخلي الرمز اللي وصلك قدامك:

1. `docker compose logs api | grep "otp send"`: يظهر سطر وحد لكل إرسال، فيه `result=ok` ورقم مخفي مثل `0780****567` و`provider_id=sms-…` و`cost=25`.
2. `docker compose logs api | grep <الرمز>`: لازم ما يطلع أي شي.
3. بالمتصفح افتح أدوات المطوّر، ثم Network، ثم ردود `otp/send` و`otp/verify`: ما بيها الرمز، بس الحالة.
4. `docker compose exec db psql -U sijil -c "select phone, attempts, verified_at, left(code_hash,12) from otp_challenges order by created_at desc limit 3;"`: الرمز غير موجود، بس hash طويل.

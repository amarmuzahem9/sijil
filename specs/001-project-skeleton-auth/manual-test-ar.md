# خطوات التجربة اليدوية — الفيزة 001: هيكل المشروع وتسجيل الدخول

كل الحسابات والأرقام هنا وهمية. لا تستخدم بيانات حقيقية.

## أولاً: على جهازك (محلياً)

**التجهيز:**

```bash
docker compose up -d --build
docker compose exec api python -m app.cli seed-demo
```

افتح `https://localhost`، واقبل تحذير الشهادة المحلية.

| # | الخطوة | النتيجة المتوقعة | ✓ |
|---|---|---|---|
| 1 | ادخل بالأدمن الرئيسي: `+964 770 000 0000` وكلمة السر من `SUPERADMIN_PASSWORD` | تفتح صفحة «تغيير كلمة السر» مباشرة | |
| 2 | جرّب فتح `https://localhost/admin` قبل الحفظ | ترجع لصفحة تغيير كلمة السر | |
| 3 | أدخل كلمة سر جديدة أقصر من 8 أحرف | «كلمة السر يجب أن تكون 8 أحرف على الأقل» | |
| 4 | أدخل كلمة سر جديدة صحيحة واحفظ | تفتح لوحة الأدمن: بار جانبي يمين بالصفحات الـ 11، وبالأعلى الاسم و«أدمن رئيسي» | |
| 5 | افتح كل صفحة من البار الجانبي | كل صفحة فارغة ومكتوب فيها «قريباً» | |

| 13 | ادخل برقم غير صالح مثل `12345` | «رقم غير صالح» تحت الحقل | |
| 14 | ادخل برقم غير مسجّل | «رقم الهاتف أو كلمة السر غير صحيحة»، نفس رسالة كلمة السر الخاطئة | |

**إيقاف حساب أثناء الجلسة (للمطوّر فقط):**

```bash
docker compose exec db psql -U sijil -c "UPDATE users SET is_active=false WHERE phone='07700000001';"
```

- في نافذة المسوّق حدّث الصفحة. المتوقع: صفحة الدخول مع رسالة «الحساب موقوف، راجع الإدارة».
- لإرجاع الحساب استخدم نفس الأمر مع `is_active=true`.

**إلغاء القفل قبل انتهاء الـ 15 دقيقة (للمطوّر فقط):**

```bash
docker compose exec db psql -U sijil -c "UPDATE users SET locked_until=NULL, failed_logins=0 WHERE phone='07700000001';"
```

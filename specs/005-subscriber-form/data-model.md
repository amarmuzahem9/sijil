## audit_log (existing)

New action: `draft.deleted`, with `entity_type = "draft"`, `entity_id = <draft uuid>`, and
`before = {created_at, updated_at, tower_code, image_count, missing_count}`. It never holds
card data, names, the phone or file names (FR-019).

## Validation rules (draft_validation, research R9)

A draft can be saved with any value within the length limits. `missing` lists, in page order:

| Field | Missing when | Code |
|---|---|---|
| `image_front`, `image_back` | no row for the side | `required` |
| `first_name`, `father_name`, `grandfather_name`, `great_grandfather_name`, `surname`, `mother_first_name`, `mother_second_name` (each its own item, in this order) | empty | `required` |
| `mother_third_name`, `mother_surname` | never listed (optional) | — |
| `national_id` | empty → `required`; not 12 digits after normalization | `invalid_national_id` |
| `family_number` | empty after trim | `required` |
| `location` | lat/lng null | `required` |
| `address`, `landmark` | empty after trim | `required` |
| `area_id`, `tower_id`, `plan_id` | null | `required` |
| `phone` | empty → `required`; normalization fails | `invalid_phone` |

**Name rule** (all nine name fields, research R12): trim, collapse inner spaces, remove
Arabic diacritics and tatweel; then only Arabic letters (U+0621–U+063A, U+0641–U+064A,
U+0671–U+06D3, which includes پ چ ژ ک گ ی) and single spaces may remain. Otherwise the save is
refused with 422 `invalid_name_text` naming the field, and nothing is saved.

Values longer than the limits are refused on save with 422 `too_long` naming the field. They are
never truncated silently.

## Lifecycle

```text
(none) ──PUT first change──► draft (version 1)
draft ──PATCH / image upload / image replace──► draft (version + 1)
draft ──DELETE by owner──► removed (rows + files) + audit draft.deleted
draft ──submit (feature 008)──► request
```
